# Configurações padrão do GitHub

Este repositório reúne os modelos e as orientações de colaboração usados como padrão nos repositórios da conta **S4MSO21**.

Ele não contém aplicações, dados operacionais, credenciais ou documentação interna.

## Padrões compartilhados

- formulários para relato de erros e sugestões de melhoria;
- modelo de pull request com validação e impacto operacional;
- política de segurança e orientações de contribuição.
